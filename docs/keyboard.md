# 接続先の設定例（iPhone・iPad）

iPhoneやiPadでGoogleマップ、YouTube、Siriを操作する設定例です。GoogleマップとYouTubeは接続先にインストールしておきます。

まず [かんたん接続ガイド](connection.md) の「Bluetoothで登録」まで進めてください。普段の操作では設定用Wi-Fiへの接続は不要です。

## ペアリング

1. ESP32を起動します。初回はWebのキー送信をOFFにしておきます。
2. 接続先の「設定 → Bluetooth」で **Steering Switch** を選択します。
3. Webの「本体設定 → Bluetooth接続」で、利用する操作の通知が「使用可能」になることを確認します。ショートカットと文字入力は「キーボード」、音量と再生操作は「メディアキー」を使います。
4. ペアリング情報は保存され、次回起動時の接続に利用されます。接続後はボタンを一度離してから操作します。

接続できない場合は、Webの「本体設定 → Bluetooth接続」で「再接続」を押します。再ペアリングが必要な場合は「ペアリングを削除して再起動」を使い、接続先のBluetooth設定でも「このデバイスの登録を解除」します。同時に接続できる端末は1台です。Bluetoothで音声を中継する機能はありません。

## GoogleマップとYouTubeを開く

1. 接続先の「ショートカット」アプリで新しいショートカットを作成します。
2. 「Appを開く」アクションを追加し、Googleマップを選択。「車載 Googleマップ」などの名前で保存します。
3. YouTube用も同様に作成します。ショートカットアプリ内で両方を実行し、目的のアプリが開くことを確認します。
4. 「設定 → アクセシビリティ → キーボードと入力 → フルキーボードアクセス」を有効にします。OSのバージョンによって「キーボード」と表示されます。[AppleのiPhone向け手順](https://support.apple.com/ja-jp/guide/iphone/ipha4375873f/27/ios/27)
5. 「コマンド」に作成したショートカットが表示されたら、その項目を選び、Webの「機能割当」で対象の機能を開いてキーの組み合わせを確認してから登録します。下表は初期値です。

| 操作 | 初期の送信キー | HIDキー番号 | 修飾キーの合計 |
|---|---|---:|---:|
| Googleマップ | Control＋Option＋Shift＋1 | 30 | 7 |
| YouTube | Control＋Option＋Shift＋2 | 31 | 7 |
| Siri | Control＋Option＋Shift＋3 | 32 | 7 |
| 画面ロック | Control＋Option＋Shift＋4 | 33 | 7 |
| アプリ一覧 | Control＋Option＋Shift＋5 | 34 | 7 |

この表のSiri・ロック・アプリ一覧の組み合わせは、フルキーボードアクセスに対応するコマンドが表示される場合、そこで割り当てます。[Appleのフルキーボードアクセス手順](https://support.apple.com/guide/ipad/ipad5f765d6f/ipados)

### Siri起動と地球儀キー

「機能割当」の「Siriを起動」は「地球儀＋S」を送ります。「キーボードで選ぶ」で地球儀とSをそれぞれ選べば、同じ組み合わせを作れます。「地球儀（🌐）」は地球儀キー単独の機能です。どちらも「ボタン割当」からテストできます。

Appleは地球儀と音声コマンドに個別のHID Consumerコードを定義しています。このファームウェアでは地球儀の信号を押した状態で通常キーを送信し、Siriのプリセットにもこの組み合わせを使います。[Appleのアクセサリ設計ガイド、表14-3](https://developer-rno.apple.com/accessories/Accessory-Design-Guidelines.pdf#page=95)

### 画面キーボードで選んで試す

1. 本体の「キー送信を有効にする」をONにし、「動作設定を保存」を押します。
2. 「機能割当」で対象の機能を開き、「キーボードで選ぶ」から地球儀、Control、Option、Shift、Commandと組み合わせるキーを選びます。同じキーをもう一度押すと選択が外れます。通常キーの選択を外すと、選択中の修飾キーだけを送信できます。「キーを試す」でその組み合わせをBLE送信します。Safariがキーを受け取ったときは「このページで受信」に表示します。iPadOSが先に処理する操作は、iPadの画面の反応で確認します。
3. 同じiPadでコマンドを登録するときは「5秒後に送信」を押し、iPadの登録欄を開きます。別の端末でWeb画面を開いている場合は、iPadをキー入力待ちにしてから「キーを試す」を押せます。
4. 「このキーを使う」で編集中のステップに反映します。「機能をテスト」でステップ全体を試し、決まったら「保存」を押します。前の設定に戻す場合は「変更を破棄」を押します。

画面キーボードにはCaps LockとHomeがあり、「F1〜F24・テンキー・その他」を開くと、ファンクションキー、テンキー、Print Screen、右側の修飾キーなどを選べます。[USB-IFのHIDキー一覧](https://www.usb.org/sites/default/files/hut1_21_0.pdf)

接続先で別のキーに設定済みの場合は、「機能割当」で対象のキー番号と修飾キーを変更して保存します。Control=1、Shift=2、Option/Alt=4、Command/GUI=8です。通常のアプリ切り替えはCmd＋Tab、ホームはCmd＋Hを送信します。[Appleのキーボード操作資料](https://support.apple.com/en-gb/guide/ipad/ipaddf61a0c2/26/ipados/26)

## 旧版で登録したパスコードの送信

数字が届くか確認するには、接続先のロックを解除して「メモ」の本文を選択します。別の端末でWebの「ボタン割当」を開き、パスコードを割り当てたカードの「数字テスト」を押します。メモにテスト用の `0123456789` が表示されれば、BLEの数字入力は動作しています。

旧版で登録済みのパスコードは、「パスコード送信」を割り当てた実ボタンの長押しで送信できます。初期設定は電話ONを800ms以上の長押しです。初期設定ではSpaceを1回送り、700ms後に数字を送信します。

ESP32には接続先の画面状態、ロック状態、入力欄、解除成功は返ってきません。ログは「手順の送信」を示すだけです。解除済みの画面で実行すると、その画面の入力欄へ数字が入る場合があるため、接続時の自動入力と自動再試行は実装していません。1回送信した後はボタンを離し、最低10秒待ってから次の長押しを行います。再起動後の初回解除など、実際に動作する画面状態は実機で確認します。

## セルラー通信とWeb設定

ステアリング操作に必要なのはBLE接続だけです。通常のナビ利用中に、接続先をESP32の設定用APへ接続し続ける必要はありません。設定は同じ車載Wi-Fiの端末、または設定用APへ接続した別のスマートフォン／PCからも変更できます。

設定用APにはインターネットの中継機能がありません。接続先を設定用APにつないだままセルラー通信がどう扱われるかは端末側のネットワーク動作によるため、設定後は通常利用するネットワークへ戻してください。操作する端末自身が提供するテザリング先へ接続できる前提にはしていません。

## Web画面のキーボードが消える場合

タッチ端末でWebの入力欄を選ぶと、Bluetooth接続を保ったままキー送信を一時停止します。「完了」を押すか入力欄から離れるとキー送信が再開します。Wi-Fi設定の入力には、欄の直下に表示されるキーも使えます。

iPadで日本語などを入力するときに画面キーボードが出ない場合は、画面下部のキーボードメニューから「キーボードを表示」を選びます。[Appleのキーボード切り替え手順](https://support.apple.com/ja-jp/guide/ipad/ipaddd28d7ed/ipados)
