# 配線と回路定数

対象はESP32 DEVKIT V1 / ESP-WROOM-32、3.3Vで読み取れる抵抗ラダー式スイッチです。コネクターの端子番号や線色は車種・年式・ハーネスにより異なります。信号線とスイッチ共通線を実測してから接続してください。純正機器と並列接続する設計ではありません。

## 基本配線

| ESP32端子 | 用途 |
|---|---|
| GPIO36 / VP / A0 | KEY1（通話・電話ON・電話OFF） |
| GPIO39 / VN / A3 | KEY2（MUTE・音量±・MODE・曲送り／戻し） |
| GPIO34 / A6 | オプションの保護済みACC検出信号。初期状態では無効 |
| GPIO25 | 状態LED：1kΩ → LEDアノード、LEDカソード → GND |
| 3V3 | スイッチ測定用プルアップ電源 |
| GND | スイッチの抵抗ラダー共通線、測定回路のGND |
| 5V / VIN | 安定化した5V電源。USB給電でも動作確認可能 |

各系統を次の回路で読みます。KEY2にも同じ回路を独立に用意します。

```text
ESP32 3V3
    |
 Rpullup 330Ω（参考値）
    |
    +---------- 車両スイッチ KEY1
    |                 |
    |            スイッチ内の抵抗ラダー Rsw
    |                 |
    |                GND（スイッチ共通）
    |
  1kΩ（ADC直前の直列保護抵抗）
    |
    +---------- GPIO36
    |
  100nF
    |
   GND
```

ADC端子には3.3V系のクランプ／ESD保護を設け、配線は短くします。GPIO36・39・34には内部プルアップがないため、外付け抵抗が必要です。GPIO12は起動設定にも関係するため、旧コードのLED端子からGPIO25へ変更しています。車載の12VはESP32の電源端子やADCへ直接接続せず、逆接・電圧変動・過渡電圧への対策を持つ車載用5V電源を使用します。

旧資料の3.3Fコンデンサー直列による電源保持は、その容量計算だけでは実用条件を確定できません。直列セルの電圧分担、充電電流、逆流、消費電流、保持時間を別途確認します。初版の基本配線には含めません。

## 電圧・ADC・推定抵抗値による判定

新規設定では校正済みの電圧をmVで判定します。ADC判定は12bitの実測値0〜4095を使います。Ω判定は `analogReadMilliVolts()` の校正電圧を5サンプルの中央値で平滑化し、次の式で推定します。

```text
Rsw = Rpullup × Vadc / (Vsupply − Vadc)
```

「本体設定 → 入力の詳細設定」の供給電圧には実際の3V3電圧をmVで、プルアップ抵抗には実際に取り付けた抵抗をΩで入力します。Webで値を変更しても部品そのものは変化しません。

ADCが4090以上、電圧が供給電圧の20mV以内など、抵抗値を安定して計算できない場合は「測定不可」とします。Ω判定ではキー操作を発火させません。ADC値は理想的な `電圧×4095/3300` とは一致しないため、判定単位の変更時に範囲を自動換算しません。

330Ωの場合、資料の未押下抵抗で測定点は約3.10Vとなり、ESP32の測定上限に近づきます。Ω判定で未押下が測定不可になる場合はADC判定を使用するか、プルアップを680Ω〜1kΩ程度へ変更して電圧を測定範囲内に収め、回路定数の設定と全ボタンの再校正を行います。これも実機で確認する回路例です。[EspressifのADC資料](https://docs.espressif.com/projects/arduino-esp32/en/latest/api/adc.html)

単位を変更するときは、送信をOFFにして単位と回路定数を設定し、未押下と全ボタンを新しい単位で学習してからまとめて保存します。途中の提案値は未保存のまま保持できるため、旧範囲と重なる状態を最終設定として保存する必要はありません。

## ACCを後から追加する場合

GPIO34には、ACC ONでHIGH、OFFでLOWとなる**保護済み0〜3.3V信号**を与えます。初期のOFFしきい値1000mVはGPIO34端子上の電圧です。車両側の12V値ではありません。ONの確認には、しきい値＋100mV以上が必要です。

旧資料の10kΩ／3.3kΩ分圧は12Vで約2.98V、14.4Vで約3.57Vとなるため採用しません。保護回路のない単純な分圧器だけで車両信号をつながないでください。入力が起動直後からLOWでもロックを送信せず、一度ONを確認してから、設定した時間以上のOFFを検出して1回だけロックします。電源保持は最大のロックマクロ時間＋余裕を満たす必要があります。学習中・BLE未接続・送信OFF時はACC連動も停止します。
