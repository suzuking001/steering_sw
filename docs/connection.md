# かんたん接続ガイド

**普段使うのはBluetoothだけです。Wi-Fiは設定を変えるときに使います。車載ルーターは必須ではありません。**

| つなぐもの | 方法 | いつ使う？ |
|---|---|---|
| ESP32 ↔ 操作する端末 | Bluetooth | ステアリングスイッチで接続先を操作するとき |
| ESP32 ↔ タブレット・スマホ・PC | 設定用Wi-Fi | ボタンの学習・割り当て変更をするとき |
| ESP32 ↔ PC | USB | 最初のプログラム書き込みとパスワード確認 |

## 1．最初だけ、PCで準備

1. ESP32をUSBケーブルでPCにつなぎます。
2. PlatformIOでプログラムを書き込みます。詳しい操作は [README](../README.md#初回の使い方) を参照してください。
3. PlatformIOのシリアルモニター（115200bps）を開きます。
4. `SteeringSW-xxxxxx` というWi-Fi名と、`Password` の値を控えます。

このパスワードは**設定用Wi-Fiへの接続時だけ**使います。Web画面でのログインやパスワードの再入力は不要です。端末の画面ロック解除用パスコードとは別です。

シリアル表示を見逃したら、モニターから `SETUP` と改行を送ると再表示できます。

## 2．設定画面を開く

1. ESP32に電源を入れます。設定用Wi-Fiは自宅のWi-Fiの登録状況にかかわらず、電源投入時に自動で起動します。
2. タブレットまたはスマートフォンの「設定 → Wi-Fi」で **SteeringSW-xxxxxx** を選び、控えたパスワードを入力します。
3. 画面が自動で開いたら、そのまま設定できます。

自動で開かない場合は、ブラウザーのアドレス欄へ **http://192.168.4.1/** と入力します。「インターネット未接続」という表示は設定用Wi-Fiでは正常です。

Wi-Fi名が見つからないときは、**電源を入れた後で、ESP32の「BOOT」ボタンを3秒押して離します。** 設定用Wi-Fiの起動を再試行します。

Apple製タブレットの自動表示画面で接続が解除される場合は、Wi-Fi名の横の詳細ボタンから「ネットワークに接続」を選び、案内に応じて「インターネットに接続せずに使用」を選択し、ブラウザーで上記アドレスを開きます。表示の有無や文言はOSによって異なります。[Appleの接続手順](https://support.apple.com/ja-jp/102554)

設定画面では「ボタン割当」でカードを追加し、カードの「学習」で入力系統と中心値を登録します。その後、最後に「本体設定」でキー送信をONにして保存します。

## 3．操作する端末をBluetoothで登録

1. 操作する端末で「設定 → Bluetooth」を開きます。
2. **Steering Switch** を選びます。
3. 登録後、Web画面に「BLE 操作可能」と表示されれば接続できています。

これを最初に一度行うと、次回は保存したペアリング情報を使って再接続します。接続後はスイッチを一度離してから操作します。GoogleマップやYouTubeを開く設定は [対応端末での設定例](keyboard.md#googleマップとyoutubeを開く) を参照してください。

## 家庭・車内のWi-Fiにつなぎ、PCから開く

1. まず設定用Wi-Fiで画面を開き、「本体設定 → Wi-Fi接続」に接続先のSSIDとWi-Fiパスワードを入力します。ESP32側は2.4GHzのWi-Fiを使用します。
2. 「Wi-Fi設定を保存して接続」を押します。画面下の「保存・適用」でも、入力したWi-Fiと端末パスコードをまとめて保存できます。
3. 「保存済み：SSID」が出れば設定は保存されています。続いて「接続中」「IPアドレスを取得中」「接続成功」の表示を確認します。保存できても、パスワード等が違うと接続には成功しません。
4. **接続成功後に表示される「同じネットワークのPCから開くURL」** をPCのブラウザーへ入力します。「URLをコピー」も使えます。

例：画面に `http://192.168.0.45/` と表示された場合は、そのURLをPCで開きます。これは例です。実際の画面に表示されたアドレスを使用してください。

**`192.168.4.1` は、SteeringSW- の設定用Wi-Fiへ直接つないだ端末のためのアドレスです。** PCを普段の家庭Wi-Fiにつないだまま使う場合は、接続成功後に表示されるPC用URLを使用します。`steering-sw.local` が使えない環境でも、IPアドレスのURLで開けます。

PCもESP32と同じ家庭・車内LANへ接続してください。PCが5GHz、ESP32が2.4GHzでもルーター側で同じLANなら利用できます。ゲストWi-Fiや端末間通信を禁止する設定では、同じルーターでも通信できない場合があります。

接続できないときは、保存済みSSIDとエラー表示を確認して修正するか、「保存した設定で再接続」を押します。Wi-Fi設定は電源を切っても残ります。USBの `SETUP` でも、接続成功していればPC用URLを確認できます。

## 入力欄と保存済み表示

Wi-Fiパスワードと端末パスコードは、**保存後も入力した内容が欄に残ります**。「入力したパスワード／パスコードを表示」を選ぶと、そのページで入力した文字を確認できます。入力中・未保存・保存済み・エラーを各欄のそばに表示します。

ページを開き直したときは、保存済みの秘密情報を読み出さないため入力欄は空になりますが、「登録済み」と表示します。空欄だから未保存という意味ではありません。同じSSIDでWi-Fiパスワードを変更しない場合は空欄のまま保存できます。パスワードなしのWi-Fiを使う場合は専用のチェックを入れます。

端末パスコードも、空欄のままでは登録済みの内容を変更しません。削除は「削除」ボタンから行います。

## 普段の使い方

ESP32に電源を入れ、操作する端末のBluetoothをONにして使います。設定が済んだら、操作する端末のWi-Fiはいつもの接続先へ戻して構いません。ステアリング操作はBluetooth経由で続きます。

設定を変更したくなったら、Wi-Fi一覧から設定用Wi-Fiを選んで設定画面を開きます。別のスマートフォンやPCで設定しながら、操作する端末は通常のナビ用通信を使う構成でも利用できます。

設定用Wi-Fiはインターネットを中継しません。通常のWi-Fi経由で開く場合も、Webログインは不要です。

## 文字が入力しにくいとき

ESP32は外付けキーボードとして操作する端末につながるため、画面のキーボードが出にくくなる可能性があります。

入力欄をタップするとESP32のBluetoothが一時停止します。タッチ端末のキーボードが出ない場合、SSID・Wi-Fiパスワード・端末パスコード欄の下に入力用のキーが出ます。SSIDとWi-Fiパスワードでは英数字・記号を入力でき、端末パスコードには数字キーが出ます。「完了」を押すか入力欄から離れるとBluetoothの再接続が始まります。設定は各欄の保存ボタンか画面下の「保存・適用」で保存します。

## 接続できないとき

| 状況 | 操作 |
|---|---|
| SteeringSW- がWi-Fi一覧にない | 起動後にBOOTを3秒長押し |
| Wi-Fiにはつながるが画面が出ない | ブラウザーで `http://192.168.4.1/` を開く |
| Wi-Fiのパスワードが分からない | USBシリアルから `SETUP` を送って再表示 |
| 端末の画面キーボードが出ない | Wi-Fiやパスコードの入力欄の下に表示されるキーを使う |
| Bluetooth接続できない | 「本体設定 → Bluetooth接続」で有効設定を確認し、「再接続」を押す。再登録するときは「ペアリングを削除して再起動」を使い、端末側でも登録を解除 |
| 家庭Wi-Fi上のPCから開けない | 「本体設定 → Wi-Fi接続」の接続成功とPC用URLを確認。192.168.4.1 と混同しない |
| 入力欄が空だが保存できたか分からない | 欄のそばの「保存済み」「登録済み」を確認。再表示時に秘密情報は読み出さない |
| 接続したがボタンが効かない | 校正、未押下範囲、「キー送信ON」、接続先の端末のキー割り当てを確認 |

この簡単接続機能はプログラムの更新後に使用できます。設定画面の自動表示、BOOTボタンによる実機操作は、実機検証の対象です。
